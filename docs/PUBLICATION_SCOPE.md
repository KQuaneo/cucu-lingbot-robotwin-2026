# 公开范围、证据边界与脱敏

## 包含

完成/取消/准备中的19项实验索引、6k训练log与loss、clean BF16/FP32及randomized FP32逐任务结果、历史LoRA与准入日志、对应训练/评测配置与修改代码、柜子增强审计、Colab迁移检查、RLinf静态适配检查、四组残差RL代码与真实采样/梯度证据。

可用录像共1628段：clean BF16 500、clean FP32 500、randomized FP32 500、首次固定残差16、多任务REINFORCE72、PPO24、观测条件多轮16。Release还包含逐chunk NPZ和小型RL actor/optimizer参数。这些小网络参数不等于6k主模型权重。

## 不包含

按用户明确范围，不上传HF6k大权重、DCP可续训存档及优化器、重复权重分块、部分下载的训练数据、13.3GB原比赛提交ZIP。也不宣称5k或早期LoRA权重已备份；此前用户取消保存，原日志与清单可用。

源代码中的无关上游大二进制、示例训练数据、PDF论文、Git历史bundle及缓存没有作为本队实验结果上传。第三方源代码/许可证和我们实际使用的配置/补丁保留。原始分享ZIP不直接上传，而按当前范围重新打包，去除Apple下载元数据、凭据风险及重复大权重。

## 脱敏与哈希

公开副本将原SSH地址替换为`YOUR_SERVER_IP`，原Mac用户名替换为`LOCAL_USER`，绝对项目目录替换为`/path/to/project`，并去掉账号核对、操作状态、上传路径和带下载签名的查询参数。未改变原始本地文件。第三方版权中的公开作者署名与联系邮箱予以保留。

`manifests/file_inventory.json`对每个来源给出源相对路径、公开路径、所在证据包、存储位置、原文件SHA和公开副本SHA；脱敏文件两者可能不同。录像与NPZ不做内容编辑。大附件使用Release以避免将视频和轨迹塞入Git历史。

## 未核验部分：观测条件RL补充对照

本地保存了3轮共12条新训练轨迹、两次非零更新、最终4条验证轨迹（1/4成功）、actor v0–v3和optimizer状态。补充初始网络同种子control的脚本存在，但截至2026-10-27本地没有其完成状态、最终配对审计或对应录像；SSH旧端口连接已关闭，未能恢复远端证据。

因此此归档只认定16条可用回合，不把计划中的额外4条control计入结果，也不对观测条件RL声称配对提升。`audit_conditional.py`是保存的审计程序，不意味着已成功执行该最终审计。

## 读结果时的边界

- 最终JSON每任务10次不是官方100次标准。
- 官方后训练模型的adjust_bottle 10/10不代表基础模型或全任务成绩。
- 早期adjust_bottle日志显示5/10但实际policy回合仅5/5，保留作valid-retry问题证据，不当作合规10回合结果。
- 发布的官方参考成绩与取消的本地官方BF16对照分开，不将参考值伪装成本地实测。
- 小样本残差RL、数据增强方案及静态RL适配检查不等于大模型正式RL训练或可靠增益。
- 天池2026-10-26接收记录为当时“待评测”，没有在此归档认定后续审核/排名结果。
