# 有观测条件残差网络与多轮在线采样

本次以4个冻结的6k FP32服务运行click_bell/demo_clean，计划3轮×4个新在线回合，每轮更新后重新采样，再做4个新验证回合。不是动作专家或6B主模型微调；不修改原权重与提交包。用户说明实例随时可能回收，因此逐轮保存并持续同步，完成数量以实际日志/状态为准。控制器硬截止20:20香港时间，实例提前消失则只保留真实已完成证据。

观测输入171维：当前三路相机各3通道4×4空间池化特征（144维）、当前14维关节状态、基础动作块首步的12个手臂关节目标、动作块进度。MLP 171→32(tanh)→12，再用0.5*tanh限制高斯均值，5900个可训练参数。特征只有粗粒度图像/状态，不是训练新的视觉编码器。

每个动作块根据最新观测重新算mean，采样z~N(mean,0.25² I)，动作偏移0.02*tanh(z)弧度；较此前试验扩大最大偏移范围，夹爪不变。每块最多执行25步，实际执行数记录在回执中。

训练：每轮只用该版本策略新采集的4条真实轨迹，终局成功reward1/失败0；per-chunk clipped PPO actor目标，episode Monte Carlo reward减leave-one-out baseline、clip0.2，Adam lr1e-3、2个优化epoch、梯度范数上限1。计算所采集观测上的平均单chunk Gaussian KL，超过0.02时回滚该优化epoch的模型与optimizer。平均单chunk KL不是整条轨迹KL上界。每回合对执行过的chunk log probability求和，不把输出的未执行动作另算样本。

网络参数和Adam状态随版本继承，下一轮采样加载新网络。若一轮所有奖励相同，优势全为0，允许真实零更新；版本号增加只表示已处理一批，不等于发生非零梯度更新。更新次数按parameter_change_norm>0统计。不能伪造奖励差异。

保存actor_vN.pt、optimizer_vN.pt、每轮update JSON、逐chunk图像/状态/基础动作/修正动作/特征/old_mean/latent/epsilon、实际执行步数、终局reward及视频。collect_trial.py只采闭合轨迹，逐成员SHA核验。

合成单元测试使用独立/tmp目录，只测试feature维度、梯度与条件响应，不纳入任何真实采样/成功率。实际试验的完整性与行为条件响应还须独立审计。训练轮次的新种子彼此分离，验证使用新种子；没有未训练网络在相同验证种子的配对对照，因此不能用训练回报/最后验证回报声称性能提高。
